# Almaty Trip — Design Merged
기존 편집 기능과 컬러풀한 포스터형 모바일 디자인을 결합한 버전입니다.

- 일정 완료 체크
- 일정 추가 / 수정
- 준비물 체크 / 추가
- 항공편
- 루트
- 추천 장소
- localStorage 저장
- PWA / Service Worker

GitHub Pages에는 압축을 푼 내부 파일을 저장소 루트에 업로드하세요.
기존 사진은 `img/` 폴더의 같은 파일명을 그대로 사용합니다.
예: `img/bigalmaty.jpg`, `img/zenkov.jpg`, `img/medeu2.jpg`.

일정 편집은 현재 기기 브라우저의 localStorage에 저장되며 GitHub 파일 자체를 변경하지 않습니다.
